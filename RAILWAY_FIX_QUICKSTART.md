# 🚨 RAILWAY DEPLOYMENT FIX - QUICK GUIDE

## Masalah: Tampilan Ancur di Railway

Website tampak "ancur" karena **CSS tidak load** dan kemungkinan **database tidak terkoneksi**.

---

## ✅ SOLUSI CEPAT (5 MENIT)

### Step 1: Set Environment Variables di Railway

1. **Buka Railway Dashboard:**
   - https://railway.app
   - Login → Pilih project `mangakumangamu-production`

2. **Tambah Database PostgreSQL:**
   - Klik "New" → "Database" → "PostgreSQL"
   - Railway akan auto-generate `DATABASE_URL`

3. **Set Environment Variables:**
   - Klik tab "Variables"
   - Tambahkan variables berikut:

```env
DATABASE_URL=<auto-generated dari Railway PostgreSQL>
NEXTAUTH_URL=https://mangakumangamu-production.up.railway.app
NEXTAUTH_SECRET=<generate dengan command di bawah>
NODE_ENV=production
```

**Generate NEXTAUTH_SECRET (di terminal local):**
```bash
# PowerShell
[Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes((New-Guid).ToString()))

# Atau jika punya openssl
openssl rand -base64 32
```

---

### Step 2: Deploy Database Migration

**Install Railway CLI:**
```bash
npm install -g @railway/cli
```

**Login & Link Project:**
```bash
railway login
railway link
```

**Run Migration:**
```bash
railway run npx prisma migrate deploy
```

Atau:
```bash
railway run npx prisma db push
```

---

### Step 3: Redeploy

**Option A - Auto Redeploy:**
Railway akan auto-redeploy setelah ENV vars di-set.
Tunggu ~2-3 menit.

**Option B - Manual Redeploy:**
```bash
# Push dari local
git add .
git commit -m "fix: add missing env vars"
git push origin main
```

**Option C - Railway Dashboard:**
1. Deployments tab
2. Klik tombol "Redeploy" di latest deployment

---

### Step 4: Verify

1. **Buka website:**
   https://mangakumangamu-production.up.railway.app

2. **Hard refresh:**
   - Ctrl + Shift + R (Windows/Linux)
   - Cmd + Shift + R (Mac)

3. **Check DevTools Console:**
   - F12 → Console tab
   - Tidak boleh ada error merah

## 🐛 TROUBLESHOOTING

### Problem 1: CSS Still Not Loading

**Cause:** Tailwind CSS tidak generate di build

**Fix:**
```bash
# Local - test production build
npm run build
npm start

# Jika local works tapi Railway tidak:
# 1. Clear Railway cache
# 2. Redeploy from scratch
```

---

### Problem 2: Database Connection Error

**Cause:** DATABASE_URL salah atau database belum exists

**Fix:**
1. Railway → Add PostgreSQL database
2. Copy DATABASE_URL dari Variables tab
3. Paste ke Railway Variables
4. Run migration: `railway run npx prisma migrate deploy`

---

### Problem 3: 500 Internal Server Error

**Cause:** Missing environment variables

**Fix:**
Check semua required ENV vars:
- ✅ DATABASE_URL
- ✅ NEXTAUTH_URL
- ✅ NEXTAUTH_SECRET

---

### Problem 4: Blank White Page

**Cause:** JavaScript runtime error

**Fix:**
1. Open DevTools Console
2. Read error message
3. Biasanya: Prisma Client not generated
4. Solution: Ensure build command includes `prisma generate`

## 🚀 ALTERNATIVE: Deploy Ulang dari Scratch

Jika masih bermasalah, deploy ulang:

### 1. Delete Existing Railway Project
- Railway Dashboard → Settings → Delete Service

### 2. Create New Railway Project
```bash
# Install Railway CLI
npm i -g @railway/cli

# Login
railway login

# Init new project
railway init

# Add PostgreSQL
railway add postgresql

# Set other ENV vars
railway variables set NEXTAUTH_URL=https://your-url.up.railway.app
railway variables set NEXTAUTH_SECRET=<your-secret>

# Deploy
railway up
```

### 3. Run Migration
```bash
railway run npx prisma migrate deploy
```
